# Woodfrog Animations

This project contains the Woodfrog automated demo animations.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. View animations:
   Open [http://localhost:3000/animations](http://localhost:3000/animations) to see the primary animation.

## Endpoint

- `/animations`: Main automated demo animation.
