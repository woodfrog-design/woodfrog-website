### How to add/replace:
1.  Navigate to the `public` folder in your project root.
2.  Create a folder named `logos` if it doesn't exist.
3.  Drop your SVG files into `public/logos/` and rename them to match the table above.
4.  The website will automatically pick up the new images.

> [!NOTE]
> Ensure the SVGs have good contrast or are colored appropriately for a dark background.
